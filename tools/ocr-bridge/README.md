# LeadBridge OCR Bridge

Локальный служебный компонент для кнопки «Запустить OCR» в MAX Chat Local Exporter.

- слушает только `127.0.0.1:17848`;
- принимает только JSON-запрос с внутренним заголовком расширения;
- разрешает только существующие ZIP-файлы `MAX_CHAT_EXPORT_...zip`;
- запускает локальный `max_chat_ocr.py`;
- по запросу расширения открывает системное окно для выбора уже скачанного `MAX_CHAT_EXPORT_...zip`;
- пишет результат в `LeadBridgeKSO/ocr_results`, а журнал в `LeadBridgeKSO/logs`;
- отдаёт расширению локальный статус процесса и последнюю диагностическую строку при ошибке;
- не отправляет архив, изображения или OCR-результат в интернет.
